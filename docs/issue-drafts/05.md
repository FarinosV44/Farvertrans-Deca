## Goal
Move from docs to a runnable product. Create the real application scaffold on `develop` using the recorded stack and make it boot locally with a minimal browser-verifiable shell.

- Next.js 15 App Router + TypeScript.
- App shell, global styles, design tokens from `docs/design/IMPLEMENTATION-BRIEF.md`.
- Environment validation.
- Supabase client/server helpers.
- Prisma schema implementing the data model in `docs/02-functional-spec.md`.

- Health endpoint.
- Basic error boundary / 404.
- Test runner + lint + typecheck + build scripts.
- `.env.example` with placeholders only; no secrets.
