# SEO — canonical host, indexable pages, conventions

Short reference for anyone adding or reviewing public content. Written as part of the 2026-09
technical SEO audit (`docs/decisions.md` D-105).

## Canonical host

`https://decaprofesional.es` (no `www`) is the single canonical host. Every request to
`https://www.decaprofesional.es/...` gets a permanent redirect to the same path and query string on
the non-www host (`next.config.ts` → `redirects()`). Every indexable page also sets a
self-referencing `alternates.canonical` to its own non-www URL.

## Indexable pages

- `/` — homepage / product entry point. Primary intent: the DeCA generator as a product ("DeCA
  Profesional").
- `/deca-gratis` — primary intent: generating a DeCA for free. Owns the "gratis" keyword; the
  homepage does not compete for it (see D-105).
- `/generador-deca` — the indexable transactional landing page for the generator (`/crear` itself is
  `noindex`, see below).
- `/soy-obligado` — interactive "am I required to do a DeCA" tool.
- `/que-es-el-deca`, `/deca-obligatorio-2026`, `/como-hacer-un-deca` — **cornerstone guides**. Every
  other SEO page and CMS article links to these three with varied, descriptive Spanish anchor text.
- `/requisitos-deca`, `/datos-obligatorios-deca`, `/deca-pdf-qr`, `/quien-esta-obligado-deca`,
  `/deca-vs-cmr`, `/deca-autonomos`, `/deca-empresas-transporte`, `/deca-agencias-transporte`,
  `/deca-cargadores` — the rest of the `content/seo/pages.ts` cluster, each with one distinct
  `intent`.
- `/guias`, `/blog` and their published `[slug]` pages — the CMS content engine
  (`lib/content/cms.ts`), editable without a deploy.
- `/revision-legal` — the public author/reviewer page explaining the DeCA Profesional ↔ PRAETORIA
  relationship and naming any credited legal reviewer.

## Intentionally excluded routes

- `/crear` — the DeCA creation wizard (an application/form screen). `noindex, follow` in its own
  metadata and **not listed in the sitemap**; `/generador-deca` is the indexable equivalent that
  drives traffic to it.
- `/entrar`, `/registro`, `/recuperar`, `/panel`, `/admin`, `/operadores`, `/claim`, `/api`, `/d/*`
  (individual DeCA documents) — all disallowed in `robots.ts` and never in the sitemap. `/d/*` in
  particular must never become crawlable: it is where the actual customer documents live.

## Sitemap

`GET /sitemap.xml`, generated by `app/sitemap.ts`. Only public, canonical, indexable pages are
listed. `lastmod` is always a genuine content date — the SEO cluster's own `lastReviewed`, the CMS
`updatedAt`, or a hand-set real date for the remaining core routes (`CORE_LAST_MODIFIED` in
`sitemap.ts`) — **never** the deployment timestamp. `priority`/`changeFrequency` are not emitted:
they are not used as ranking or crawl-budget signals.

## Writing a new article (guide or blog post)

Every new `ContentItem` (`prisma/content-seed.ts`, or the admin editor) should define:

- `title` / `seoTitle` — a distinct, non-duplicating primary intent versus every other indexable
  page (check the cannibalisation list below before publishing).
- `metaDescription` — 70–160 characters, specific to this article.
- `canonicalOverride` — only if the article's canonical URL should differ from its own
  `/guias/[slug]` or `/blog/[slug]` (rare; leave unset otherwise).
- `publishedAt` — the real publication date.
- `lastReviewedAt` — the real date of the last normative/factual review, updated whenever the
  content is actually re-checked — never bumped just because something else on the site shipped.
- `authorName` — `"Equipo DeCA Profesional"` for house content (never the retired "DeCA Fácil"
  name).
- `legalReviewerName` — **optional**. Only set when a named reviewer (e.g. a PRAETORIA lawyer)
  genuinely reviewed this specific article. Never invented or defaulted.

For a new page in the static `content/seo/pages.ts` cluster, the equivalent fields are `title`,
`description`, `intent` (must be unique across the cluster), `lastReviewed`, and the optional
`legalReviewer`.

## Keyword cannibalisation

Before adding or retitling a page, check its primary intent against: `/`, `/deca-gratis`,
`/generador-deca`, `/crear` (excluded from the sitemap/index), `/deca-obligatorio-2026`,
`/blog/cuenta-atras-deca-5-octubre-2026`, and the rest of `content/seo/pages.ts`'s `intent` fields.
Two pages should never target the same primary intent — either give the new page a genuinely
different angle or consolidate into the existing page. See `docs/decisions.md` D-105 for the
homepage/`/deca-gratis` and `/deca-obligatorio-2026`/blog-countdown-post decisions made in the
2026-09 audit.
